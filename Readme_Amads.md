# Nombre del proyecto
Sistema para la gestion de un hotel

# Tecnologías de desarrollo

- Lenguaje: PHP
- Framework: Laravel, Tailwind
- Gestor de base de datos: MySQL Workbench

# Metodología ágil seleccionada para el desarrollo del proyecto

Se utilizó una metodología ágil mixta entre Scrum y Kanban (Scrumban) para el desarrollo del proyecto. El equipo trabajó mediante sprints para organizar las tareas en períodos definidos, aplicando características de Scrum, mientras que el seguimiento y control del avance se realizó mediante un tablero visual en GitHub Projects, utilizando estados de trabajo como “To do”, "In Progress" y “Done”, característica propia de Kanban.

# Herramienta seleccionada para la implementación de la metodología

## GitHub Projects

Esta herramienta nos permitió:

- Gestionar tareas mediante Issues.
- Asignar responsables.
- Organizar actividades por sprints.
- Dar seguimiento al estado de cada tarea.
- Controlar el avance general del proyecto mediante un tablero visual.
